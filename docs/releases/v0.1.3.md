# Akagi Web 0.1.3

## Changes since 0.1.2

- Fix missing suggestions after riichi, so the drawn tile remains visible during automatic tsumogiri turns.
- Fix skipped ron and tsumo opportunities after riichi. When automatic play is enabled, these wins are handled normally.
- Fix empty automatic-action log records, so logs now show the action process and results.

# Akagi Web 0.1.3（简体中文）

## 相较于 0.1.2 的更新

- 修复立直后建议不再显示摸打牌的问题，自动摸切时也能看到摸到的牌。
- 修复立直后荣和、自摸被跳过的问题；开启自动打牌后，这些和牌机会也会正常处理。
- 修复自动操作日志为空的问题，日志可正常记录操作过程和结果。
