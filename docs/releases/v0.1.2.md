# Akagi Web 0.1.2

## Changes since 0.1.1

- Add mid-game recovery for Majsoul three-player and four-player games. Click **Recover and continue** in the Capture panel to recover the current game; the page reloads at most once.
- Show a suggestion marked **act manually** when recovery restores a pending action. Follow this suggestion manually; subsequent live suggestions and automatic play continue as usual, with automatic play enabled separately.
- Mark incomplete history as **partial**, excluding it from complete-match placement and PT statistics. Recovery within the same match retains previously captured complete rounds.
- Enable the suggestion overlay when upgrading an existing configuration. You can turn it off in Settings; this does not enable automatic play.
- Keep the Settings action bar visible while scrolling.

# Akagi Web 0.1.2（简体中文）

## 相较于 0.1.1 的更新

- 新增雀魂三麻／四麻中途局面恢复。在采集面板点击 **「恢复并继续」** 恢复当前对局，页面最多刷新一次。
- 恢复当前待行动局面后，可显示 **「恢复建议 · 请手动操作」**。这条建议需手动执行，后续实时建议和自动打牌照常使用；自动打牌仍需自行开启。
- 不完整历史标记为 **「中途采集」**，不计入完整对局的名次及 PT 统计；同场恢复保留此前采集的完整小局。
- 升级已有配置时默认开启建议悬浮窗，可在设置中关闭；不会因此开启自动打牌。
- 设置页面滚动时，操作栏保持可见。
