# Akagi Web 0.1.2

## Changes since 0.1.1

- Add mid-game state recovery for Majsoul three-player and four-player games. The Capture panel provides a **Recover and continue** button and recovery status. Recovery is user-triggered and reloads the uniquely bound supported official page at most once.
- Rebuild the game tracker, bundled model and automatic-action context together. After recovery completes, a confirmed pending action window can immediately show a suggestion marked **act manually**; this restored suggestion is never executed automatically. Subsequent valid live windows retain normal decisions and opt-in automatic actions.
- Bind decisions and input to the current capture generation and server action window. Discard stale decisions on cancellation or window changes, and prevent superseded connections from affecting the current game.
- Mark incomplete history as **partial**, excluding it from complete-match placement and PT statistics. Same-match recovery retains previously captured complete rounds, and existing history remains readable.
- Enable the suggestion overlay once when upgrading an existing configuration, while preserving later user choices and leaving automatic play opt-in. Keep the Settings action bar visible while scrolling.
- Update the English and Chinese installation/build guides with platform-specific tooling checks, upstream differences, and security/privacy guidance.

# Akagi Web 0.1.2（简体中文）

## 相较于 0.1.1 的更新

- 新增雀魂三麻／四麻中途局面恢复。采集面板提供 **「恢复并继续」** 按钮及恢复状态；恢复由用户主动触发，对唯一绑定的受支持官方页面最多刷新一次。
- 同步重建局面追踪、内置模型和自动操作上下文。恢复完成后，已确认的当前待行动窗口可立即显示 **「恢复建议 · 请手动操作」**，该建议不会自动执行；后续有效实时窗口保持原有决策和需要主动开启的自动操作逻辑。
- 决策和输入绑定当前采集代次及服务端操作窗口。取消或窗口变化时作废旧决策，已被取代的连接不能影响当前对局。
- 不完整历史标注为 **「中途采集」**，不参与完整对局的名次及 PT 统计。同场恢复保留已采集的完整小局，已有历史仍可读取。
- 升级已有配置时一次性开启建议悬浮窗，之后保留用户选择，且不会因此开启自动打牌；设置页面滚动时操作栏保持可见。
- 更新中英文安装与构建指南，补充各平台工具检查、上游差异及安全／隐私说明。
