# Akagi Web 0.1.0

The first public Akagi Web release, maintained from [shinkuan/Akagi](https://github.com/shinkuan/Akagi).

## Features

- Support the official Majsoul and Tenhou web clients.
- Provide bundled local suggestions for three-player and four-player games.
- Connect to an existing Edge/Chrome browser or launch an independent browser.
- Show suggestions in an overlay, save game history and provide automatic play when you enable it.

For downloads and setup, see the [installation guide](https://github.com/Etakind/Akagi-web#download-and-install).

# Akagi Web 0.1.0（简体中文）

## 功能
