# Akagi Web 0.1.0

The first public Akagi Web release, maintained from [shinkuan/Akagi](https://github.com/shinkuan/Akagi). Akagi Web has an independent version sequence; 0.1.0 is not an upstream Akagi downgrade.

## Features

- Majsoul and Tenhou official web clients, with bundled local three-player/four-player inference.
- Attach to an existing Edge/Chrome browser or launch an isolated Chromium profile.
- Local advice, overlay, history, Inspector and explicitly enabled automatic play.
- Improved Edge endpoint discovery, guarded automatic input and CSP-compatible tile rendering.
- No MITM certificates, system proxy, cloud inference/review, external executable bots or remote themes. Update checks and user-requested official browser downloads remain available.

## Downloads

Choose the ZIP matching your system: Windows x86_64, macOS Intel, macOS Apple Silicon, Linux x86_64 or Linux ARM64. Linux also provides DEB/RPM packages. Linux requires GTK3/WebKitGTK 4.1 and compatible system libraries; refer to the [installation and build guide](https://github.com/Etakind/Akagi-web#packages-and-running).

Each target includes an asset inventory and SHA256 checksums. This release is unsigned and not notarized. Verify the download source and hashes; a checksum alone does not prove publisher identity.

CDP grants access to browser sessions: keep debugging on loopback and prefer an isolated profile. Automated play may violate game rules and lead to account penalties. Client changes can break automation; Akagi pauses instead of refreshing a game. Review the [maintenance and security guide](https://github.com/Etakind/Akagi-web/blob/main/docs/FORK_MAINTENANCE.md).

# Akagi Web 0.1.0（简体中文）

Akagi Web 首个公开版本，基于 [shinkuan/Akagi](https://github.com/shinkuan/Akagi) 维护。采用独立版本序列，0.1.0 不表示对上游 Akagi 的降级。

## 功能

- 支持 Majsoul、Tenhou 官方网页，内置三麻/四麻本地推理。
- 可附加常用 Edge/Chrome，或启动隔离的 Chromium 浏览器目录。
- 保留本地建议、悬浮窗、历史、Inspector 和主动开启的自动打牌。
- 改进 Edge 调试地址发现、自动操作边界与 CSP 下的牌面显示。
- 不使用 MITM 证书、系统代理、云推理/复盘、外部可执行机器人或远端主题；保留更新检查和用户主动下载官方浏览器。

## 下载

按系统选择 ZIP：Windows x86_64、macOS Intel、macOS Apple Silicon、Linux x86_64 或 Linux ARM64。Linux 另提供 DEB/RPM，需要 GTK3/WebKitGTK 4.1 及兼容系统库，详见[安装与构建指南](https://github.com/Etakind/Akagi-web/blob/main/README.zh-CN.md)。

每个目标附资产清单与 SHA256。本版本未签名、未公证，请核对来源和摘要；摘要本身不能证明发布者身份。

CDP 可访问浏览器会话，请仅使用回环监听并优先选择隔离目录。自动打牌可能违反游戏规则并导致账号处罚。
客户端变化可能使自动操作失效，Akagi 会暂停，不会自动刷新对局。详见[维护与安全指南](https://github.com/Etakind/Akagi-web/blob/main/docs/FORK_MAINTENANCE.zh-CN.md)。
