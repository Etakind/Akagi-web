# Akagi Web 0.1.1

## Changes

- Add automatic-action records for Majsoul three-player and four-player games. View countdowns, execution steps and results in **Game → Events → Automatic actions**.
- Show recent automatic actions in the overlay when Majsoul automatic play is enabled, with an adjustable number of records.
- Highlight unconfirmed actions in red in both the event records and the overlay.
- Allow adjustment of the overlay font size.
- Clarify first-run setup: save your settings to enter the full interface. The independent browser can retain your login when you reuse its profile.

# Akagi Web 0.1.1（简体中文）

## 更新内容

- 新增雀魂三麻／四麻自动操作记录，可在 **「对局 → 事件记录 → 自动操作」** 查看倒计时、执行过程和结果。
- 开启雀魂自动打牌后，悬浮窗可显示最近的自动操作，支持调整显示条数。
- 事件记录与悬浮窗中的「未确认」操作以红色显示。
- 支持调整悬浮窗字号。
- 明确首次设置后需要点击保存才能进入完整界面；复用独立浏览器目录时，可保留登录状态。
