# Akagi Web 0.1.1

## Changes

- Majsoul three-player/four-player automatic-action records: next-input countdowns, execution steps, retries and server-confirmed results.
- Game → Events now includes an Automatic actions tab. In-memory history survives rounds and same-match reconnects; a confirmed new match clears it.
- Overlay shows recent actions while Majsoul autoplay is effectively enabled, with 1–10 configurable rows (default 4).
- Unconfirmed actions display red text in both interfaces. Overlay base font size is configurable from 12–24px (default 14), scaling text and row heights together.
- Clarified first-run configuration: save settings to enter the full interface. The automatically opened independent browser retains login state when its persistent profile is reused, subject to server session expiry.
- Fixed frontend configuration and bundle-size warnings without relaxing CSP or raising warning thresholds.
- Release drafts are verified and published using their release ID.

## Limits and downloads

This release does not display remaining turn time. Countdown observation does not change Lua action selection or retry policy; Tenhou autoplay is unchanged.
An input request alone is not success. Insufficient feedback after 5 seconds is Unconfirmed; matching late feedback may confirm it.
Records are memory-only and cannot fully distinguish simultaneous identical manual and automatic actions.

ZIPs are provided for Windows x64, macOS Intel/Apple Silicon and Linux x64/ARM64. Linux also provides DEB/RPM packages.
Asset inventories and SHA256 checksums accompany each target. This release is unsigned and not notarized; checksums alone do not establish publisher identity.
See the [installation guide](https://github.com/Etakind/Akagi-web#packages-and-running).

Automatic play is opt-in and may violate game rules or lead to account penalties. Client changes can break automation.
Keep CDP on loopback and protect the isolated browser profile; do not use ranked games to test automation.

# Akagi Web 0.1.1（简体中文）

## 更新内容

- 雀魂三麻/四麻自动操作记录：下一次输入倒计时、执行步骤、重试及服务端反馈结果。
- 「对局 → 事件记录」新增「自动操作」页签。内存记录跨小局和同场重连保留，确认开始新一场后清空。
- 雀魂自动打牌有效开启时，悬浮窗显示最近操作，条数可设为 1～10（默认 4）。
- 两处「未确认」记录全部文字改为红色。悬浮窗基准字号可设为 12～24px（默认 14），文字与行高同步缩放。
- 明确首次配置后需要保存才能进入完整运行界面。自动打开的独立浏览器可通过复用持久化目录保留登录状态，但会话可能过期。
- 修复前端配置与包体积警告，不放宽 CSP，不提高警告阈值。
- 发布草稿通过 release ID 核验和公开，避免标签接口无法定位草稿。

## 边界与下载

本版不显示剩余出牌时间。倒计时观察不改变 Lua 动作选择和重试策略；天凤自动操作行为不变。
发出输入请求不等于成功；5 秒内反馈不足显示「未确认」，匹配的迟到反馈仍可确认。
记录仅保存在内存中，协议不能完全区分同时发生的相同手动操作与自动点击。

提供 Windows x64、macOS Intel/Apple Silicon、Linux x64/ARM64 ZIP；Linux 另提供 DEB/RPM。
各目标附资产清单与 SHA256。本版本未签名、未公证，摘要本身不能证明发布者身份。
详见[安装与运行指南](https://github.com/Etakind/Akagi-web/blob/main/README.zh-CN.md)。

自动打牌需主动开启，可能违反游戏规则并导致账号处罚；客户端变化可能使适配失效。
CDP 仅使用回环地址，请保护隔离浏览器目录，不要在段位场测试自动操作。
