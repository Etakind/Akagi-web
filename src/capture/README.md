# 浏览器采集

`chromium/` 是唯一后端，只接入 Majsoul / Tenhou 的官方 HTTPS 页面。
端口 0 启动隔离目录，非零附加用户授权的回环调试服务，不安装证书、不修改系统代理。

- `launch.rs` / `detect.rs`：标准 HTTP 发现及固定 DevToolsActivePort 路径；只读定位文件，不访问 Cookie/会话数据库。
- `connection.rs`：授权分类、超时和有限传输重连；403 不循环重试。
- `discovery.rs` / `cdp.rs`：官方页面发现、唯一绑定和 WS/脱敏 HTTP 订阅；Tenhou 开启自动操作时才准备客户端适配。
- `flow.rs`：每个 WS 独立解析器；原数据在内存处理，记录及广播使用脱敏副本。

停止附加不关闭常用浏览器；独立模式只管理自己启动的进程。页面失效清理自动操作上下文，普通输入失败不会刷新游戏。雀魂用户主动触发「恢复并继续」时，先关闭唯一已识别的游戏连接一次，失败后允许刷新原页面一次；导航、停止捕获或切换平台会取消恢复。
`recovery.rs` 管理批次屏障、捕获代次及状态；`chromium/recovery.rs` 管理有限重连／刷新策略。
脚本响应拦截在订阅取消时释放，不让失效的自动操作适配阻塞页面加载。
