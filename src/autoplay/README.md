# 网页自动操作

必须主动开启。`manager.rs` 根据本地建议、当前牌局和合法动作调用 `majsoul/` 或 `tenhou/` 生成操作步骤，`cdp_input.rs` 经本机 CDP 执行。
仅绑定唯一所选官方页面；配置/页面变化递增绑定代数，动作和重试前检查开关、代数及决策窗口。
连续未确认输入会暂停，不刷新牌桌。

Majsoul 使用画布输入，`verify.rs` 观察客户端实际输入命令确认。
Tenhou 使用 DOM 操作及已识别脚本中的弃牌入口；缺入口或脚本结构不符时停止动作。
独立启动先准备适配再导航，附加已加载页面由用户在安全时机自行重新进入，不自动刷新。
`delay/` 的 Lua 环境仍禁止文件、进程、网络访问。
本次恢复实现但未跑自动测试/真实输入，验收限制见维护指南。
