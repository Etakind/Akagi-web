# 内置本地模型

只运行 `akagi-native` / `akagi-native3p`，四麻/三麻按牌局选择；模型编译进应用，无需 Python 或在线推理。

- `manager.rs` 接收 post-tracker 事件、维护批次与决策时机，向建议总线发布结果。
- `runner.rs` 只定义本地 BotRunner 接口；`native.rs` 使用内置引擎，`supervisor.rs` 管理生命周期。
- `types.rs` 定义响应与本地分析元数据。自动操作单独消费建议，仍受主动开关、唯一官方页面和决策窗口约束。

外部机器人发现/下载/依赖同步/子进程，以及云 API、购买/订阅和复盘接口已经删除。
旧外部选择迁移为内置模型并关闭自动操作；旧机器人目录不自动清理。
开发用模型训练、转换工具保留，不进入应用运行或分发路径。
本次只有生产编译，没有执行模型回归或真实对局；详细边界见根维护指南。
